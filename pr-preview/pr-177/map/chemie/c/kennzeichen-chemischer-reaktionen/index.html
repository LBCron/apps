Dieser Baustein

An Beobachtungen erkennen, dass eine chemische Reaktion abgelaufen ist

→

Darauf bauen auf

  • Eine chemische Reaktion von einer Zustandsänderung unterscheiden
  • Synthese und Analyse unterscheiden
  • Mit einem Versuch zeigen und erklären, dass bei einer Reaktion die Gesamtmasse gleich bleibt
  • Eine Reaktion als Wortgleichung aufschreiben
  • Eine Verbrennung als Reaktion mit Sauerstoff beschreiben und sagen, was zum Brennen nötig ist
  • Erklären, wie eine Änderung der Temperatur die Geschwindigkeit einer Reaktion beeinflusst
  • Beschreiben, welche Energieformen bei einer Reaktion ineinander umgewandelt werden · Strang Energie
